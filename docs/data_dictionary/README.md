# Data Dictionary

Create one file per source by copying `TEMPLATE.md`:
`nvd.md`, `cisa_kev.md`, `mitre_attack.md`, `cwe.md`, `cisa_advisories.md`.

Fill it in **when the collector is built**, using the real downloaded data (never guessed fields).
Notes to remember:
- NVD records do not prove a vulnerability is exploited in the wild; CISA KEV does.
- Follow each site's terms of use, rate limits and robots guidance.
